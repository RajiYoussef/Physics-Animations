# Solution to Laplace's Equation Using Machine Learning

This project explores numerical solutions to
Laplace's equation using machine learning,
particularly Physics-Informed Neural Networks (PINNs).

## Governing Equation

∇²u = 0

where u represents a scalar potential field.

## Objectives

- Solve Laplace's equation using neural networks.
- Incorporate boundary conditions into training.
- Visualize the learned potential field.
- Compare predictions with analytical solutions.
